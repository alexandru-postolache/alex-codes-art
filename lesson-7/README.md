# Geometric Abstract Art (Lesson 7)

A generative composition of stacked, rounded rectangles that zigzag left and right down the canvas — a geometric abstract art piece built with p5.js.

## What it does

- Draws a column of rectangles with alternating left/right alignment
- Randomizes each rectangle's width within min/max bounds
- Applies rounded corners on alternating sides for a ribbon-like look
- Switches between three color palettes via `p5.gui.js` controls
- Tweaks item count, padding, corner radius, and width ranges live

## Run it

```bash
python3 -m http.server 8081
```

Open http://localhost:8081/lesson-7/index.html.
