1. The Grid of Possibilities

Each cell doesn't start empty — it starts with all possible tiles. This is the superposition: every cell simultaneously holds every option until a decision forces it to commit. In the visualization above, uncollapsed cells shimmer with faded previews of their remaining possibilities.

2. Entropy — The Brain of the Algorithm

Entropy measures uncertainty. A cell with many options has high entropy; one with few has low entropy. The algorithm always picks the cell with the lowest entropy — the place where it knows the least, but where a decision will have the most impact. Toggle the Entropy Heatmap to see this in action: bright cells are uncertain, dark cells are nearly decided.

3. The Collapse Event

When a cell is chosen, it collapses — one tile is selected from its remaining options (weighted by probability). Watch for the golden pulse: that's a collapse happening. This is the moment of decision, the point of no return.

4. Constraint Propagation — The Ripple Effect

One decision doesn't stay local — it reshapes everything around it. When a cell collapses, its neighbors lose any options that are no longer compatible. Those changes cascade outward like a wave. The cyan ripple you see spreading from each collapse is constraint propagation in action.

5. Failure and Contradiction

Sometimes the algorithm paints itself into a corner: a cell has no valid options left. This is a contradiction — shown as a red flash. It means the constraints are unsatisfiable given the choices made so far. The grid resets and tries again. This isn't a bug; it's a fundamental property of constraint satisfaction.

6. The Result

When every cell has collapsed without contradiction, you get a complete, valid pattern — one that satisfies every adjacency rule. Same rules, different random choices, different universes. Hit New to see another.

Wave Function Collapse isn't really about tiles or grids. It's about watching decisions shape a system — one constraint at a time.
