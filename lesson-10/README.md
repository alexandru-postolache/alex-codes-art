# Noisy Circles (Lesson 10)

Animated circles that pulse, shift, and morph over time — built from **polar coordinates** and **Perlin noise**, with colors generated by `p5.colorGenerator`.

## What it does

- Traces concentric closed shapes by walking angles from 0 to `TWO_PI`
- Offsets each vertex with noise-driven displacement for organic motion
- Animates continuously by feeding `frameCount` into the noise function
- Offers Tweakpane controls for resolution, curve count, noise strength, speed, and color mode (tints, shades, triadic, tetradic)

## Run it

```bash
python3 -m http.server 8081
```

Open http://localhost:8081/lesson-10/index.html.
